## About The Project

This is a mini practice project built in Unity. The initial idea was to create a roguelike-style game inspired by the **Re:Zero** universe. Currently, it serves as a prototype showcasing basic 2D movement, combat, and enemy AI mechanics.

### ⚙️ Implemented Features

* **Player Controller:** Basic movement including walking and jumping.

* **Combat System:** Basic attacking mechanics and taking damage.

* **Game Loop:** Health points (HP), death screen, and game restart functionality.

* **Enemy AI:**

  * *Melee Enemies:* Chases the player to attack in close combat.

  * *Ranged Enemies:* Shoots projectiles and tries to maintain a safe distance from the player.

### 🎨 Assets & Graphics Disclaimer

**Please note:** All graphics, sprites, and animations currently in the game were generated using AI (Artificial Intelligence). They serve strictly as **temporary placeholders** and do not represent final game art.

### 📋 Planned Features (From the Idea Board)

Though the project is paused, the following features were planned:

* Dash mechanic and critical hits.

* Floating damage numbers and smooth HP bar drain.

* Charged attacks and ultimate weapon abilities.

* Secondary items/weapons (e.g., Emilia's amulet).

* A Hub area (village or mansion) with merchants and level selection.

* A complete State Machine for enemies (idle, wander, search, chase, attack, flee).

# Re:Zero Unity Roguelike (Тренировочный проект)

> ⚠️ **Статус: Временно заброшен / Приостановлен**
> *Этот проект создавался ради практики работы в Unity и на данный момент заморожен на неопределенный срок.*

## О проекте

Небольшой мини-проект для практики в движке Unity. Изначально планировался как около-рогалик по мотивам вселенной **Re:Zero**. На данный момент представляет собой базовый прототип с реализованным передвижением, боевкой и ИИ противников.

### ⚙️ Реализовано на данный момент

* **Управление:** Ходьба и прыжки.

* **Боевая система:** Реализована базовая атака и получение урона (HP и HP-бар для Субару).

* **Игровой цикл:** Экран смерти, звуки получения урона/смерти и полный рестарт игры.

* **ИИ противников:**

  * *Ближний бой:* Преследует и атакует вблизи.

  * *Дальний бой:* Держит расстояние при атаке, чтобы не подходить вплотную.

  * *Система кулдаунов:* Задержки между атаками привязаны к оружию и врагам.

### 🎨 Графика и ассеты

**Важное примечание:** Вся графика, спрайты и анимации, представленные в проекте, были сгенерированы с помощью ИИ (Искусственного Интеллекта). В данный момент они служат исключительно в качестве **временных заглушек**.

### 📋 Планы и идеи (Из Trello/Канбан доски)

Несмотря на то, что проект отложен, в планах (на скриншоте доски) были следующие фичи:

* Рывок (дэш) и критический урон (с тряской экрана).

* Вылетающие цифры урона и плавное убывание полоски здоровья.

* Заряженная атака и ультимативная способность оружия.

* Второе оружие / амулет Эмилии / парирование на ПКМ.

* Хаб в виде деревни или особняка с торговцами и выбором уровня.

* Полноценная State Machine для врагов (стоит, блуждает, ищет, догоняет, атакует, убегает).
